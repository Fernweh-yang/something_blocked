# Python 代码调试教程

## 使用 `print` 语句调试

在 Python 中，`print` 语句是最基础和最常用的调试工具之一。通过在关键位置插入 `print` 语句，可以轻松地检查变量的值和程序的执行流。下面是一些使用 `print` 语句进行调试的常见方法。

### 基本用法

在函数中插入 `print` 语句以输出计算结果和变量值：

```python
def add_numbers(a, b):
    result = a + b
    print(f"Adding {a} and {b}, result is {result}")  # 打印调试信息
    return result

sum = add_numbers(5, 3)
print(f"Sum is {sum}")
```

### 调试变量值

在代码中适当位置打印变量的值：

```python
def calculate_area(width, height):
    print(f"Width: {width}, Height: {height}")  # 打印变量值
    area = width * height
    return area

area = calculate_area(10, 5)
print(f"Area is {area}")
```

### 调试循环和条件语句

在循环或条件语句中打印迭代次数和条件判断：

```python
for i in range(5):
    print(f"Iteration {i}")
    if i % 2 == 0:
        print(f"{i} is even")
    else:
        print(f"{i} is odd")
```

### 调试函数调用

在函数调用前后打印调试信息：

```python
def process_data(data):
    print(f"Processing data: {data}")
    # 假设这里有复杂的处理逻辑
    processed = [d * 2 for d in data]
    print(f"Processed data: {processed}")
    return processed

data = [1, 2, 3]
result = process_data(data)
print(f"Result: {result}")
```

### 打印函数调用栈

查看函数调用栈来理解程序的执行顺序：

```python
import traceback

def foo():
    bar()

def bar():
    print("In bar")
    traceback.print_stack()

foo()
```

解决维度报错（例如张量维度不匹配）时，可以使用 `print` 语句来跟踪和验证数据的形状。下面是一些常见的步骤和方法来通过 `print` 语句解决维度报错问题：

### 1. 打印数据的形状

首先，打印涉及的张量或数组的形状，以确认它们的维度是否如预期：

```python
import numpy as np

# 创建两个不同维度的数组
a = np.random.rand(3, 4)
b = np.random.rand(4, 5)

# 打印形状
print(f"Shape of a: {a.shape}")
print(f"Shape of b: {b.shape}")

# 尝试进行矩阵乘法
result = np.dot(a, b)
print(f"Shape of result: {result.shape}")
```

### 2. 验证操作的输入和输出形状

在执行涉及多个张量的操作（例如矩阵乘法、拼接等）时，确保所有输入的形状都是兼容的，并打印每一步的形状：

```python
import torch

# 创建两个不同维度的张量
x = torch.randn(2, 3)
y = torch.randn(3, 4)

# 打印张量的形状
print(f"Shape of x: {x.shape}")
print(f"Shape of y: {y.shape}")

# 进行矩阵乘法
z = torch.matmul(x, y)
print(f"Shape of z: {z.shape}")
```

### 3. 打印操作前后的数据形状

当数据经过多个处理步骤时，确保每一步的输出维度都是符合预期的：

```python
def process_data(data):
    print(f"Input data shape: {data.shape}")
    data = data.reshape(-1)  # 改变形状
    print(f"Reshaped data shape: {data.shape}")
    return data

# 创建一个张量
data = torch.randn(2, 3, 4)
processed_data = process_data(data)
print(f"Processed data shape: {processed_data.shape}")
```

### 4. 调试模型的输入和输出形状

在构建神经网络模型时，确保输入和输出的形状匹配预期：

```python
import torch
import torch.nn as nn

class SimpleNN(nn.Module):
    def __init__(self):
        super(SimpleNN, self).__init__()
        self.fc1 = nn.Linear(10, 20)
        self.fc2 = nn.Linear(20, 5)

    def forward(self, x):
        print(f"Input shape: {x.shape}")
        x = self.fc1(x)
        print(f"After fc1 shape: {x.shape}")
        x = self.fc2(x)
        print(f"After fc2 shape: {x.shape}")
        return x

model = SimpleNN()
input_data = torch.randn(3, 10)  # 3个样本，每个样本10维
output = model(input_data)
print(f"Output shape: {output.shape}")
```

### 5. 确保维度匹配

对于需要特定维度匹配的操作（如拼接、逐元素操作等），确保所有操作的数据维度是兼容的：

```python
a = torch.randn(2, 3)
b = torch.randn(2, 3)

print(f"Shape of a: {a.shape}")
print(f"Shape of b: {b.shape}")

# 拼接操作
concatenated = torch.cat((a, b), dim=0)
print(f"Shape of concatenated: {concatenated.shape}")
```

### 总结

1. **打印形状**：打印涉及的张量或数组的形状以确认维度。
2. **逐步验证**：检查数据经过每一步处理后的形状。
3. **检查操作兼容性**：确保所有操作的输入和输出维度匹配。
4. **调试模型**：在模型的前向传播过程中打印张量的形状。
4. **维度报错**：通过print调整维度的变换。

通过这些方法，你可以更容易地识别和解决维度不匹配的问题。


### 使用 `print` 调试的最佳实践

1. **保持简洁**：避免在生产环境中使用过多的 `print` 语句。你可以用条件控制是否打印调试信息。
2. **清晰描述**：在 `print` 语句中提供有意义的描述，以便容易理解打印出的信息。
3. **清理调试信息**：在最终代码中移除不再需要的调试 `print` 语句，以保持代码整洁。
